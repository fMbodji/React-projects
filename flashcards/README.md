# Description
This web app is an interactive flashcard study tool specifically designed for Computer Science students to help them review data structures and algorithms. It features a series of questions and answers that cover key topics in these areas. Users can flip through flashcards, with questions on the front and answers on the back, categorized by difficulty level (Easy, Medium, Hard). Each difficulty level is visually distinct, making it easy to track progress and focus on specific areas. The app also provides intuitive navigation with "Next" and "Previous" buttons, allowing seamless browsing through the content.

Time spent: **6** hours spent in total
